## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/thariq-code/Data_Analyst_portfolio.git
```

### 2. Navigate into the project

```bash
cd Data_Analyst_portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The portfolio will then be available on the local Vite development URL shown in your terminal.

---

## 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
